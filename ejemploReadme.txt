# 🚗 Buscador de Autos

Una aplicación web moderna para buscar y filtrar autos según marca, año, precio, puertas, transmisión y color. Desarrollada con JavaScript moderno, HTML5 y CSS3.

## 📋 Descripción

Este proyecto es un buscador interactivo de autos que permite a los usuarios filtrar una base de datos de vehículos utilizando múltiples criterios. La interfaz es intuitiva y responsiva, utilizando el framework Skeleton CSS para un diseño limpio y moderno.

### ✨ Características

- 🔍 **Búsqueda múltiple**: Filtra por marca, año, precio mínimo/máximo, puertas, transmisión y color
- 📱 **Responsive**: Diseño adaptativo que funciona en dispositivos móviles y desktop
- ⚡ **JavaScript Moderno**: Utiliza ES6+ con funciones de flecha, destructuring y más
- 🎨 **Interfaz limpia**: Basada en Skeleton CSS para un look moderno y minimalista

## 🛠️ Tecnologías Utilizadas

- **HTML5**: Estructura semántica de la aplicación
- **CSS3**: Estilos personalizados con Skeleton CSS y Normalize.css
- **JavaScript (ES6+)**: Lógica de filtrado y manipulación del DOM
- **Google Fonts**: Fuente Staatliches para tipografía moderna

### Dependencias

- [Skeleton CSS](http://getskeleton.com/): Framework CSS ligero
- [Normalize.css](https://necolas.github.io/normalize.css/): Reset CSS cross-browser

## 🚀 Instalación y Uso

1. **Clona el repositorio:**

   ```bash
   git clone https://github.com/tu-usuario/buscador-autos.git
   cd buscador-autos
   ```

2. **Abre el proyecto:**
   - Abre `index.html` en tu navegador web
   - O usa un servidor local (recomendado para desarrollo)

3. **Servidor local (opcional):**

   ```bash
   # Con Python
   python -m http.server 8000

   # O con Node.js
   npx serve .
   ```

## 🎯 Cómo Usar

1. Selecciona los criterios de búsqueda en los desplegables
2. Los resultados se actualizan automáticamente a medida que cambias los filtros
3. Los autos que coinciden con todos los criterios seleccionados aparecerán en la sección de resultados
