# 💰 Calculadora de Préstamos

Una aplicación web sencilla para calcular el pago mensual de un préstamo según el importe, la tasa de interés y el plazo en meses. Desarrollada con HTML5, CSS3 y JavaScript.

## 📋 Descripción

Este proyecto permite a los usuarios ingresar el monto del préstamo, la tasa de interés anual y el número de meses para pagar. La calculadora actualiza automáticamente el pago mensual al cambiar alguno de los valores.

### ✨ Características

- 🧮 **Cálculo automático**: Usa la fórmula de interés para mostrar el pago mensual en tiempo real.
- 📱 **Diseño limpio**: Interfaz simple y centrada para una experiencia fácil.
- ⚡ **JavaScript básico**: Lógica de cálculo con acceso directo al DOM.
- 🎯 **Entrada validada**: Los campos aceptan valores dentro de rangos definidos para evitar datos fuera de rango.

## 🚀 Demo en Vivo
Abre `index.html` en tu navegador para usar la calculadora.

## 🛠️ Tecnologías Utilizadas

- **HTML5**: Estructura de la aplicación.
- **CSS3**: Estilos personalizados y diseño responsivo básico.

## 🚀 Instalación y Uso

1. Abre el proyecto en tu editor o navegador.
2. Abre `index.html` directamente en tu navegador.
3. Ingresa el monto del préstamo, la tasa de interés y los meses de pago.
4. El valor de pago mensual se mostrará automáticamente.

## 🎯 Cómo Usar

1. Ingresa el monto del préstamo en pesos.
2. Ajusta la tasa de interés anual.
3. Selecciona la cantidad de meses para pagar.
4. Consulta el resultado en el campo `Pago Mensual`.
